# CS-300

For these projects, the problem I was solving the need of ABCU's Computer Science department needing an advising assistance program capable of reading a file containing a list courses, sorting and displaying those courses alphanumerically sorted, and displaying an individual course alongside its prerequisies. When first approaching the problem, I needed to decide on a data structure to make use of, which are important to understand when storing, organizing, or manipulating data. The biggest roadblock I faced was in loading the input file into the data structure, though through examining previous assignments in the course, previous assignments in past courses, and trial and error, I was able to overcome it. My work on the project has helped me develop the ability to approach developing programs modularly by breaking down each necessary function of the code into separate pseudocode beforehand and reducing scope into smaller sections at a time. This project has improved how I write maintainable, readable, and adaptable programs by helping me not over-comment my code, as reducing unnecessary comments can help make the code more readable, as well as keeping the main method concise and allowing for future growth in menu options.
